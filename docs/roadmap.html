  1. Installation non invasive : un sous-dossier et une ligne dans main.js

    Diffusionmoyen

    Tout le projet vit dans Scripts\ArcadeAddons\ (nom à choisir) et l'installation se résume à ajouter import "./ArcadeAddons/main.js"; au main.js du joueur. On n'écrase plus ses scripts, et nos dossiers génériques (addons\, common\, lang\, assets\, profiles\) ne risquent plus d'entrer en collision avec les siens.

    idée›grill›spec›tickets›implement
    Recoupe peut-être la Distribution (n° ) : à trancher pendant le grill
    Questions ouvertes (4)
    • Faut-il fusionner ce chantier avec la Distribution, ou le traiter avant pour qu'elle installe déjà dans un sous-dossier ?
    • Où placer le dépôt git : à la racine du sous-dossier, avec System\ hors du dépôt ? Il faut alors revoir tests/file_layout.test.js et la règle « la racine ne contient que main.js ».
    • Chemins écrits en dur à calculer à partir du dossier du projet : Scripts\assets\... (achievement_toast.js), Scripts\.env.local (config.js), profiles\.
    • Migration des installations existantes : déplacer profiles\ et .env.local automatiquement, ou via une consigne du README ?

    Idée issue d'une évaluation externe, qui proposait une « plateforme d'extension » (loader générique, Add-ons tiers). Écartée : PinballY ne fournit pas de main.js d'origine, notre main.js est déjà un loader, et les Add-ons sont volontairement couplés (Profile store en premier, ordre imposé).

    Jeu et succèspetit

    Une échelle d'Achievements pour avoir joué une même table un certain nombre de fois (par exemple 10, 25, 50, 100 parties), avec la table la plus jouée comme Achievement Progress.

  4. Profiles marqués : admin, enfant et remise à zéro des succès

    Profilesmoyenun seul grilling

    Marquer un Profile pour changer ce qu'il voit. Un Profile admin garde les menus de configuration (Table Setup, réglages de PinballY…), les autres ont un menu principal épuré. Un Profile enfant ne voit pas les tables de la catégorie « NSFW » (déjà créée dans PinballY), qui deviennent Hidden pour lui seulement. Un bouton remet les Achievements à zéro sans toucher aux fichiers, a priori dans le menu admin.

    idée›grill›spec›tickets›implement
    Touche aussi les Weekly Challenges (Challenge Tables)
    Questions ouvertes : admin (3)
    • Comment désigner un admin : une liste ADMIN_PROFILES=… dans .env.local (recommandé) ou un champ dans profile.json, comme pour l'enfant ?
    • Quels menus cacher exactement ?
    • Que faire quand aucun admin n'est défini ?

    Désencombrer, pas protéger : aucun mot de passe. Déconseillé : fusionner avec Guest, qui sert aux visiteurs et est actif sur une installation neuve.

    Questions ouvertes : enfant (4)
    • Comment marquer le Profile : "isChild": true dans profile.json ?
    • Que faire quand la Table of the Day commune est NSFW ?
    • Les Achievements de collection comptent-ils sans les tables NSFW ?
    • Les Challenge Tables et le Random Game doivent-ils aussi les exclure ?

    Ce n'est pas un contrôle parental : aucun mot de passe.

    Questions ouvertes : remise à zéro (4)
    • Seulement le Profile actif, ou tous ?
    • Effacer seulement les annonces (notified) ou aussi la progression (parties, Streaks, stats de session) ?
    • Confirmation obligatoire : comment la rendre difficile à déclencher par erreur avec les boutons du cabinet ?
    • Menu admin, ou aussi l'Achievement List quand aucun admin n'est défini ?

  8. Distribution : installation et mises à jour

    Diffusionmoyen-gros

    Installer le projet en 30 secondes sans git : choix des Add-ons, sauvegarde de main.js, dossiers System et profiles/ et fichier .env.local préservés, puis un moyen de mettre à jour.

    idée›research›grill›spec›tickets›implement
    Réécrit la section Install des README
    Contexte

    Research : installation chez les utilisateurs de pincab, SmartScreen, GitHub Releases. Piste légère avant un vrai .exe : un zip dans GitHub Releases et un script PowerShell qui installe, écrit les ADD_ON_* cochés dans .env.local et vérifie la dernière version. Un .exe non signé déclenche SmartScreen, et une étape de build demande ton accord. Avant de diffuser, éloigner les blasons de rang (assets/rank_*.png) des emblèmes de League of Legends.
